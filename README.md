# ItzFizz Scroll-Driven Hero

A scroll-driven hero section built with:

- HTML through React JSX
- CSS
- JavaScript
- Next.js / React
- GSAP + ScrollTrigger
- Tailwind CSS
- Bootstrap 5

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## GitHub Pages

Repository name is expected to be:

`itzfizz-scroll-hero`

The project uses Next.js static export and the repository base path:

`/itzfizz-scroll-hero`

GitHub Actions builds the `out` folder and deploys it to GitHub Pages.

Live URL:

https://nandinijaiswal07.github.io/itzfizz-scroll-hero/
